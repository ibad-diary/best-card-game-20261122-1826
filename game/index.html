🔥 EMBER PACT 🔥

Duel kartu para penyihir api — kalahkan Raka si Bayang sebelum nyawamu habis.

Cara main: klik kartu untuk memainkannya (tombol 1–7), Enter mengakhiri giliran.

Mainkan 2+ kartu satu elemen dalam satu giliran untuk bonus rantai. Api + Daun = Bara Membara (+3), Air + Api = Uap Panas (+2).

Perhatikan niat lawan di tengah meja — blokir saat ia akan menyerang besar.

Masing-masing 20 nyawa. Mana naik +1 tiap ronde (maks 10). Menang bila nyawa lawan 0.
